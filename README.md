# Portfolio: omar-ramadan.dev

Source code for my personal portfolio site, **[omar-ramadan.dev](https://omar-ramadan.dev)**, which showcases my work in computer vision, autonomy, machine learning and full-stack development.

## Tech stack

- [SvelteKit](https://svelte.dev/docs/kit) / Svelte
- TypeScript
- Three.js (3D visuals) and GSAP (animation)
- Vite

## Running locally

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
npm run preview
```
